# energiebenut PWA

Installeerbare web-app voor slim energie beheer via Home Assistant.

## Installeren op je telefoon

1. Open de app-URL in Safari (iOS) of Chrome (Android)
2. Tik op "Delen" → "Zet op beginscherm" (iOS) of het menu → "App installeren" (Android)
3. De app werkt als een native app — groen energiebenut-icoon op je beginscherm!

## Functies

- 🔋 Live energieoverzicht (PV, net, accu, verbruik)
- 🚿 Boilerbesturing (laag/hoog)
- 💡 Lampen en sfeerverlichting
- 🌅 Scenes (Thuis, Avond, Nacht, Afwezig)
- 📷 Camera en media
- 🔄 Offline werken via service worker
